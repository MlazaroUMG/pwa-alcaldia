# Paquete de transferencia

Cómo usar estos documentos con la Alcaldía Auxiliar y con el Capítulo VI.

## Orden de entrega

1. `capacitacion-rapida.md` — 30 a 45 minutos presenciales.
2. `ciudadano.md` y `administrativo.md` — operación diaria.
3. `privacidad-retencion.md` — lectura conjunta con el aviso legal.
4. `tecnico.md` — para quien mantenga el código.
5. `../operacion/` — despliegue, respaldo, acta y accesos.

## Cómo impartir los manuales

- Ciudadano: celular de gama media, red de la Alcaldía, una cuenta de
  ensayo. Recorrer registro, reporte con foto y GPS, Mis tickets y muro.
- Admin: computador de escritorio. Recorrer bandeja, tablero, cierre y muro.
- No dictar secretos. El checklist de accesos solo nombra roles y correos
  institucionales, nunca contraseñas.
- Actualizar la fecha de cada manual cuando cambie una pantalla o una
  política RLS.

## Relación con el Capítulo VI

Las tablas 6.6 y 6.7 del borrador `docs/tesis/capitulo-vi.md` apuntan a este
paquete. El acta se firma después de la capacitación, no antes.
